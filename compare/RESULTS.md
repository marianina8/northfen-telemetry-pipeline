# Naive fixed limits vs. adaptive windowed detection

Same synthetic scenarios, two deterministic detectors, no model involved. **Naive** uses the fixed spec-sheet
limits in `demo/equipment.yaml` (how most tool alarms are configured). **Adaptive** is the pipeline's detector:
it learns each tool's own normal, then applies EWMA/z-score rules plus stuck and dropout checks. Cells show which sensor
flagged and at which tick. Generated by `go run ./compare`.

| Scenario | Should flag? | Naive fixed limits | | Adaptive detector | |
|---|---|---|---|---|---|
| `01-etch12-normal` | no | no flag | ✅ quiet | no flag | ✅ quiet |
| `02-cvd04-normal` | no | no flag | ✅ quiet | no flag | ✅ quiet |
| `03-imp02-normal` | no | no flag | ✅ quiet | no flag | ✅ quiet |
| `04-etch12-pressure-gradual-drift` | yes | no flag | ❌ missed | chamber_pressure @103 | ✅ caught |
| `05-cvd04-particle-spike` | yes | particles @70 | ✅ caught | particles @70 | ✅ caught |
| `06-cmp07-noisy-within-bounds` | no | spindle_vib @5 | ❌ false alarm | no flag | ✅ quiet |
| `07-imp02-vacuum-gauge-stuck` | yes (sensor fault) | no flag | ❌ missed | beamline_vacuum @60 (sensor fault) | ✅ caught |
| `08-etch12-temp-dropout` | yes (sensor fault) | no flag | ❌ missed | esc_temp @62 (sensor fault) | ✅ caught |
| `09-cvd04-threshold-boundary` | yes | no flag | ❌ missed | heater_temp @22 | ✅ caught |
| `10-cmp07-correlated-drift` | yes | spindle_vib @72, head_vib @89, pad_temp @123 | ✅ caught | pad_temp @78, head_vib @79, spindle_vib @81 | ✅ caught |

**Naive: 5/10 correct. Adaptive: 10/10 correct.**

Where they differ:
- **Gradual drift** (`04`): the pressure creeps up but never reaches the 32 mTorr spec limit, so the naive alarm never fires. The adaptive baseline moving 4σ from where it started does.
- **Noisy but stable** (`06`): the new Line 4 polisher runs rough, so vibration noise crosses the fixed limit even though nothing is wrong. That's a false alarm that trains people to ignore alarms. The adaptive detector learns this tool's own noise.
- **Stuck gauge / dropout** (`07`, `08`): a frozen or silent sensor looks "in spec" to a fixed limit. The adaptive detector treats both as sensor faults.
- **Correlated drift** (`10`): both catch it, and the fixed limit actually trips first on spindle vibration. But it sees the other two sensors only 17 and 51 ticks later, so at the moment someone gets paged the correlation that points to mechanical wear isn't visible. The adaptive detector flags all three within 3 ticks, and the pipeline groups them into one incident for one diagnosis.
- **Threshold boundary** (`09`) isn't a fair fight. It's a hand-built fixture that pins the adaptive detector's exact z = 3.0 cutoff, well inside the spec limits by design. It's included so the table covers every fixture.
